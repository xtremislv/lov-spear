How it works

Three gestures. That's the whole app.

Lov-Spear lives in the system tray with no main window. Everything happens where your mouse already is.

Drag files+Shift

Convert

Start dragging any files, press Shift, and a wheel of formats appears. Drop on one and the new file is saved right next to the original.

Drag files+Ctrl+Shift

Edit

Crop, compress, trim, merge PDFs, remove location data, OCR and 40+ more tools, without opening an editor.

Shift+Hold right-click

Launch

Anywhere on screen, aim at an app, folder or website and let go. A quick Shift+right-click still opens the normal Windows menu.

FAQ

Questions

Where is the app window?

There isn't one. Lov-Spear runs in the notification area next to the clock. Right-click its icon for jobs, recent results, watch folders and settings, or choose Welcome & settings. If you can't see the icon, click the ^ arrow on the taskbar.

How do I get the editing tools?

While dragging files, press Ctrl+Shift (or F9) instead of Shift. With the two-level layout, hover a category to open its tools in a second ring.

Does Shift + right-click break the normal Windows menu?

No. A quick Shift+right-click still opens the extended Windows menu; only a held press opens the launcher. You can also change the trigger to the mouse wheel button or a side button.

Do I need Microsoft Office?

No. Office is only used, when installed, for layout-perfect exports of Word, Excel and PowerPoint files. Everything else uses the engines included in Lov-Spear.

Store or installer: which should I use?

The Microsoft Store version updates itself and needs no warnings to install. The installer and portable ZIP on the releases page are the same app, unsigned, so Windows SmartScreen may ask you to confirm (More info → Run anyway).

Is it open source?

Yes. Lov-Spear is built on ZestDrop (MIT) and Rovyl (GPL-3.0). The changes are in the source folder of the GitHub repository.
